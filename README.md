# ML / AI Platform

Domain-agnostic infrastructure for registering datasets and model candidates, running reproducible evaluations, producing deterministic findings, and managing model lifecycle decisions across classical ML, forecasting, LLM, RAG, and agentic systems.

This repository is under initial bootstrap. Product and architecture decisions will be developed through GitHub issues and pull requests.

## Engineering platform

This repository is intended to consume the shared standards from `JCDevBot/engineering-platform` through a pinned, verified release while keeping ML/AI-specific product and architecture rules local.
